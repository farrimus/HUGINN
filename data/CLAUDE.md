# data/ -- Runtime Data

Runtime data directory. Most contents are gitignored -- generated by build scripts or created at runtime.

## Generated vs Committed

| Path | Committed? | Source |
|------|-----------|--------|
| structures/*.json | Yes | Manual configuration (one per SSU) |
| eve_universe.db | No | `python build_universe.py` (requires starmapcache.json from eve-frontier-tools) |
| gate_graph.json | No | `python build_gate_graph.py` |
| system_index.json | No | Generated at startup from eve_universe.db |
| {env}/killmails.jsonl | No | Synced hourly at runtime from Sui events |
| {env}/sessions/ | No | Created per pilot at runtime |
| {env}/memory/ | No | Created per structure at runtime |
| {env}/log_intel/ | No | Created from log uploads |
| {env}/system_knowledge.db | No | Created at runtime |

## Environment-Specific Paths

`data/utopia/` and `data/stillness/` -- selected by `DEPLOYMENT_ENV` environment variable. Each contains sessions, memory, log_intel, killmails, and the system knowledge DB.

All backend code uses `config.get_data_path(filename)` to resolve the correct environment path.

## Galaxy Database

`eve_universe.db` -- SQLite with 24,426 solar systems, gate connections, constellations, regions, and celestials. Read-only at runtime.

For schema, tables, and query patterns: `docs/DATA_REFERENCE.md` -> Galaxy Database.
Python interface: `src/galaxy_db.py` (GalaxyDB class).
